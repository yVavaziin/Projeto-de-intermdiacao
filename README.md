# EcoConnect API ♻️

API desenvolvida em Java com Spring Boot para gerenciamento de logística reversa e resíduos recicláveis.

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- HTML
- CSS
- JavaScript

---

## 📌 Funcionalidades

- Cadastro de usuários
- Cadastro de empresas
- Cadastro de resíduos
- Cadastro de máquinas
- Intermediação entre empresas e resíduos
- API REST com integração ao PostgreSQL
